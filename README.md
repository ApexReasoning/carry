# Carry

Carry is an AI teammate that keeps responsibility alive across conversations, agents, tools, machines, and time.

The repository is under active V1 construction. Start with [AGENTS.md](AGENTS.md) and the canonical documents in [`docs/`](docs/).

## Current development commands

```bash
make build
make test
make check
```

The first implementation node establishes the `carry-server` and `carry` binaries plus Machine enrollment. Product behavior is added through the vertical Nodes in [`docs/implementation.md`](docs/implementation.md).
